What is different in this viewer. The reference was rebuilt from the 7 in-house PTB- samples only (31,399 cells), dropping the 4 external Pyle samples, because the CosMx slide and the pooled reference did not represent the same tissue. Two subclusters fell below the 50-reference-cell floor once restricted and were removed (FB11 mesothelial, BC7) — cells that previously carried those labels are now assigned elsewhere. TC9 (recently-activated T) was exempted and keeps its 77 Pyle cells, since it is the population of interest. The query object is byte-identical to the combined-reference run, so every label difference here is due to the reference alone.

Annotation layers. Colour by Major Cell Type, Subcluster, T-cell activation or Tissue piece; toggle polygons; overlay marker genes or IF channels. The T-cell activation layer is not label transfer: it relabels T cells scoring above a cutoff on a 7-gene immediate-early module (EGR1, EGR2, NR4A1/2/3, IER3, KDM6B) as Early activation T cell, leaving every other cell on its transferred label. EGR3, NFKBID and VDR were requested but are not on the 6K panel. See analysis_inhouse/early_activation/00_module_score_histogram.pdf for the cutoff provenance.

Highlighting. Click the ◎ on any legend row to draw an enlarged ring around those cells — works in both point and polygon mode — or paste a list of cell IDs into the highlight box (e.g. early_activation/09_EAT_cell_ids.txt). The ring size slider controls how prominent they are.

Caveats. The slide holds one tissue block placed as two pieces (large = FOV 1-281, small = FOV 282-310) — they are not two specimens. The Proliferating / PR0 label failed marker validation on this slide: only 27.7% detect any cycling transcript and 43.9% are CD3+, so it absorbs T cells rather than marking cycling ones. Do not read it as a proliferation measure. Cells failing QC (< 100 counts, or > 2% negative-probe fraction) appear as QC_removed. Each cluster code carries its biological annotation under the code in the legend and in the hover tooltip; an orange ⚠ marks a label this slide’s own markers do not support — hover it for the evidence.
